## What we care about

- **Purpose before features** — We start with the problem, the people affected by it, and the outcome that matters.
- **Quality that lasts** — Maintainable code, secure foundations, useful documentation, and reliable delivery are part of the product.
- **Collaboration in the open** — We value respectful feedback, shared ownership, and knowledge that strengthens the whole community.
- **Progress with integrity** — We make deliberate choices, learn quickly, and remain accountable for the impact of our work.
